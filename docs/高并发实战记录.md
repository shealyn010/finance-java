## 问题记录

### 1. RabbitMQ 认证失败
- 现象: ACCESS_REFUSED - PLAIN authentication failed
- 原因: Docker run 时指定 RABBITMQ_DEFAULT_USER/PASS 只在首次初始化生效，容器已有数据卷时被忽略
- 解决: `rabbitmqctl change_password` 重置密码 + `set_permissions` 授权 vhost

### 2. MyBatis-Plus 分页 total=0
- 现象: 分页查询返回 total=0，实际数据存在
- 原因: 缺少 PaginationInnerInterceptor 分页插件
- 解决: 注入 MybatisPlusInterceptor + PaginationInnerInterceptor(DbType.MYSQL)

### 3. 深分页性能
- 无索引: page=100 → 1720ms (全表扫描)
- 加索引后: page=5000 → 154ms
- 优化措施: 添加 user_id+order_time 联合索引

### 4. AI API 限流熔断
- 信号量并发限制: 10
- 熔断阈值: 连续5次失败 → 30秒冷却 → 半开探测
- 高并发压测中 0 次触发熔断，限流器正常运行

### 5. 启动窗口期无服务
- 现象: Maven spring-boot:run 编译+启动需20-30秒，此期间 API 返回 Connection Refused
- 解决: 引入健康检查 + K8s Readiness Probe / 蓝绿部署

### 6. 外键约束缺失
- 现象: 删了用户后工单数据变成孤儿记录
- 解决: ALTER TABLE 添加 user_id 外键关联 user(id)

### 7. 高并发API压测
- 20线程×100请求=2000单，耗时6.7秒，吞吐297条/秒，0失败
- 每条请求走完整链路: 校验→外键→利润计算→MQ投递→AI分析
