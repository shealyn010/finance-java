# 企业工单AI分析模块需求文档

## 业务背景

中山市作为珠三角制造业重镇，大量中小企业在灯饰、五金、家电维修等行业运营，
日常产生大量工单（维修单、安装单、巡检单）。
传统工单管理仅做记录，缺乏智能分析能力。

## 核心功能

### 1. 工单管理
- 创建/查询工单（支持按服务类型筛选）
- 自动计算利润 = 收入 - (人工费+材料费+其他)
- 自动计算利润率

### 2. AI智能分析
- 利润分级：高利润(>40%) / 常规(10-40%) / 亏损(<10%)
- 异常检测：工时异常(>8h)、材料费占比异常(>70%)
- 经营建议：基于数据给出优化方向

### 3. Agent对话查询
- "这个月古镇的维修工单利润怎么样？"
- "哪种服务类型利润率最高？"
- "上个月有没有亏损的工单？"

### 4. 报表
- 按地点(镇区)统计利润排行
- 按服务类型统计收入/利润
- 日/月/年度报表

## 数据来源

- 方向A: 爬取中山政府采购网企业招标工单数据作为行业基准
- 方向B: 基于中山产业特征生成仿真工单数据（演示用）
- 方向C: 对接企业内部工单系统API
